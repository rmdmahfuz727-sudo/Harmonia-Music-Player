## 🎨 Design & Open Source Attributions

Harmonia is built as an independent open-source player, drawing creative and architectural inspiration from:

1. **Mochy Music** ([realidkroo/Mochy-Music](https://github.com/realidkroo/Mochy-Music)):
   - Inspiration for the warm coral/obsidian dark aesthetic, squircle card layouts, ambient color backdrop, capsule transport controls, and AudioLab soundstage interface.
2. **Sakuga VFX** ([finktheartist/sakuga-vfx](https://github.com/finktheartist/sakuga-vfx)):
   - Inspiration for keyframed anime-style spring physics, volume-preserving touch feedback, and dynamic canvas effects (bursts, rings, slashes, and onomatopoeia overlays).
3. **AndroidX Media3**:
   - High-performance background audio playback service and ExoPlayer engine.

## 🌟 Key Features

- **YouTube Music Online Client**: Search millions of tracks, explore mood/genre filters, browse trending charts, and stream seamlessly.
- **Fluid 120 FPS Performance**: Hardware-accelerated transforms using `graphicsLayer` without layout recomposition.
- **Expressive Motion**: Volume-preserving squash and spring overshoot on interactive elements.
- **Dynamic Waveform**: Animated harmonic seek bar along the playback timeline.
- **AudioLab**: 3D spatial audio field, dynamic bass boost, and acoustic reverb presets.
- **Background Playback**: Full MediaSessionService support with lockscreen controls and notification actions.
- **Local Library Discovery**: Automatic scanning and categorization of device audio files with instant search.
